# Application 03: Word Frequency Analyzer

A web application to count and rank word frequencies in any text paragraph.

## Features
- **Frequency Counter:** Calculates occurrences of each individual word.
- **Top 10 Words Bar Chart:** Visual horizontal bar chart illustrating the 10 most common words.
- **Sorted Data Table:** Full table sorted from highest to lowest occurrences with percentage of total words.
- **Stop Words Filter:** Allows toggling common English stop words (the, a, is, etc.) on or off.
- **Case Sensitivity Option:** Choose whether to treat capitalized and lowercase terms identically.
- **Vocabulary Diversity:** Shows total analyzed words, unique words, and vocabulary diversity percentage.

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla ES6)

## How to Run
Double-click `RUN.bat` or open `index.html` directly in any web browser.
